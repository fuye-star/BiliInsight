============================================================
  BiliInsight · B站热门视频数据分析与智能推荐系统
  桌面版使用说明
============================================================

一、怎么运行
------------------------------------------------------------
1. 把整个 BiliInsight 文件夹解压到任意位置（例如 D:\BiliInsight 或桌面）
2. 双击文件夹里的 BiliInsight.exe
3. 首次启动需要准备数据，会显示进度界面，大约 5-15 秒
4. 准备完成后自动进入主界面

⚠️ 重要：请不要解压到 C:\Program Files 下
   那里没有写入权限，会导致抓取数据失败。
   放到 D 盘、E 盘或桌面都可以。

⚠️ 程序运行时会在自己的文件夹下创建 data 目录
   数据库、AI 检索索引、日志都放在这里。
   想备份或迁移，直接复制整个文件夹即可。


二、能不能更新数据？
------------------------------------------------------------
能。联网时点一下就行。

打开「数据总览」页面，顶部有一张「数据更新」卡片：
   · 选择分区（科技 / 数码 / 游戏 …）
   · 选择条数（默认 40）
   · 点「立即更新数据」

几秒钟后会提示「新增 X 条 / 更新 Y 条」，页面数据同步刷新。

数据更新的原理：
   程序会访问 B站 的公开排行榜接口（1 次网络请求），
   把最新数据写入本地的 data\biliinsight.db，再重建 AI 检索索引。

没有网络时：
   程序自带一份预置数据（40 条真实视频 + 6720 条弹幕），
   打开就能看到完整图表，只是点「更新数据」会失败。


三、遇到「被风控限流」怎么办
------------------------------------------------------------
B站 对频繁请求有风控。如果提示被限流：

   1. 等 2-10 分钟再点，不要连续点
   2. 间隔越长越安全
   3. 这是 B站 的限制，不是程序坏了

程序里所有抓取都遵守「请求间隔不低于 1 秒」的合规要求。


四、AI 助手怎么用
------------------------------------------------------------
AI 助手需要接一个大模型才最完整。
不接也能用（会退化成"只检索数据、不生成回答"）。

★ 推荐方式：在界面里直接配置（不用改任何文件）
   1. 打开左侧菜单「AI 助手」
   2. 点右侧「RAG 链路状态」卡片里的「模型设置」按钮
   3. 选择服务商（DeepSeek / 通义千问 / 本地 Ollama / OpenAI 兼容）
   4. 填上你自己的 API Key，点「保存配置」
   5. 点「测试连接」—— 提示"连接成功"即可用
   6. 关掉弹窗，随手问一句试试

   同一个界面里可以保存多套配置（比如公司代理一个、自己再一个），
   点「启用」随时切换，不用重启程序。

★ 支持哪些服务商
   · DeepSeek          填自己的 Key，模型名用 deepseek-flash
   · 通义千问 DashScope 填阿里云百炼的 Key，默认 qwen-plus
   · 本地 Ollama        不需要 Key，但要先装好 Ollama 并 pull 模型
   · OpenAI 兼容        任何遵循 OpenAI 协议的服务都能填：
                        硅基流动、月之暗面、One-API 中转、
                        vLLM、LM Studio 等（地址填到 /v1 那一层）

★ 密钥安全
   · Key 会**加密后**保存在本机的数据库里，不是明文
   · 接口从不返回完整 Key，界面上只显示 sk-8****cdef 这种打码形式
   · 密钥不会上传到任何地方（除了直接发给你选的那个模型服务商）

★ 备选方式：用配置文件（适合不想开界面、或想预置给多台机器）
   1. 关闭程序
   2. 把 config.example.json 复制为 config.json
   3. 填入：
        {
          "deepseek_api_key": "sk-你的密钥"
        }
   4. 重新打开程序，首次启动会自动把它导入成一条配置

   注意：只要界面里已经有配置了，config.json 就不会再被读取
        （以界面里保存的为准）。


五、文件夹里都有什么
------------------------------------------------------------
   BiliInsight.exe      主程序，双击运行
   使用说明.txt          本文件
   frontend\            网页界面文件（不要删）
   seed\                预置数据（首次启动用，之后可删）
   data\                【运行时生成】数据库、索引、日志
   config.json          【可选】你的配置（API Key）
   _internal\           程序运行所需的依赖库（不要删）

data\logs\desktop.log  出问题时的日志，反馈时请附上它


六、常见问题
------------------------------------------------------------
Q: 双击没反应？
A: 等几秒，首次启动较慢。若仍无反应，看 data\logs\desktop.log。

Q: 提示端口被占用？
A: 程序会自动换端口。如果反复失败，关掉占用 8000 端口的程序。

Q: 图表是空的？
A: 说明数据库没数据。点「更新数据」抓一批，或检查 data 目录是否有
   biliinsight.db。删掉 data 目录再启动，程序会重新导入预置数据。

Q: 想清空所有数据重新开始？
A: 关闭程序，删掉 data 文件夹，再启动即可。

Q: 支持 Windows 7 吗？
A: 需要 Windows 10/11。界面依赖系统自带的 WebView2（Edge 内核）。
   如果提示缺少 WebView2，程序会自动改用默认浏览器打开。
